Xset — конфиденциальность

Обновлено 11.11.2026

Xset — бесплатный дневник тренировок. У приложения нет своего сервера: оно не собирает, не продаёт и не передаёт ваши данные третьим лицам. Рекламы и аналитики нет.

Где хранятся записи

Тренировки хранятся в памяти вашего браузера на устройстве. Если вы входите через Google, приложение сохраняет копию в таблицу «Xset» на вашем Google Диске — чтобы записи не пропали при смене телефона.

Доступ к Google

  • Запрашивается только разрешение drive.file: приложение видит лишь файлы, которые создало само. Остальной Диск ему недоступен.
  • Данные из Google используются только для показа и сохранения ваших тренировок внутри Xset и никуда больше не отправляются.
  • Отозвать доступ можно в любой момент: myaccount.google.com/permissions. Таблицу можно удалить с Диска как обычный файл.

Использование данных Google API соответствует Google API Services User Data Policy, включая требования Limited Use.

In English

Xset is a free workout diary with no server of its own. Workouts are stored in your browser and, if you sign in with Google, in a spreadsheet in your own Google Drive using the drive.file scope (access only to files the app created). No data is collected, sold or shared. Revoke access any time at myaccount.google.com/permissions. Use of Google API data adheres to the Google API Services User Data Policy, including the Limited Use requirements.
